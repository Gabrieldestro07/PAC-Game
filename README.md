# Fish Like a Banker

Jogo de pesca em pixel art feito no Godot. Pesque, negocie com o comerciante e registre suas descobertas no Diário de Capturas. Depois de desbloquear a Caverna Sombria, você pode desafiar o Corvo da Maldição.

## Como jogar

1. Importe o arquivo `project.godot` no Godot 4.6.
2. Pressione **F5** no editor para abrir o jogo.
3. Selecione um destino no Diário de Viagem.

## Controles

| Controle | Ação |
| --- | --- |
| A / D | Andar |
| Espaço | Pular |
| Shift | Dar um dash |
| Clique esquerdo | Interagir, pescar ou lançar o anzol em um ponto sem interação |
| Botão esquerdo segurado | Aumentar a tensão durante a pesca de tensão |
| R | Girar o item enquanto ele é arrastado no inventário |

O jogo salva o progresso localmente. O menu inclui um tutorial com os controles e as mecânicas de pesca.
